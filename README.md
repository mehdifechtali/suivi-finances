# Suivi Finances

Application web de finances personnelles : recettes, dépenses, dettes, projets d'achat ou de financement, et prévision du solde sur les mois à venir.

Construite en HTML, CSS et JavaScript, sans framework, et publiée avec GitHub Pages.
